# History of coding-lessons

**Assembled 2026-08-15** from two sources: memories that had accumulated in a personal set for want of
a cross-project one, and `LESSONS.md` from the Scatterhoard repository, which stood in for this store
before it existed. That file recorded its own intent to be replaced by a memory set, and this is it.

Links between memories were only written where the source material asserted a relation — `LESSONS.md`
names its own general forms and instances explicitly — rather than added to make the graph look
richer. That keeps the edge density representative of how memories actually get linked in use, which
matters if the set is ever used to evaluate graph traversal.

**Made adoptable 2026-09-28**: the charter was rewritten around *would hold on a different codebase*,
and an adoption guide was added under `coding-lessons-adoption-guide`, with Scatterhoard as the first
project to adopt it.

**Revised 2026-10-04, before the first release**: the recall habit moved out of the guide and into the
paragraph a project puts in its `AGENTS.md`, after sessions that read it from the guide let it fade;
and signposts were withdrawn, after a replay of one project's 38 recorded failures found they would
have been in place before 4 of them.
